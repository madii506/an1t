# An1t

Your ant trades for you. Launch a coin paired to $ANTHROPIC on Solana and get your own agent terminal.

Static site + Vercel functions (`api/`): market data (Dexscreener, Jupiter, GeckoTerminal), the ant's brain (Anthropic model through Vercel AI Gateway, rules fallback), a coin scanner and a read-only RPC relay. Trades are Jupiter swaps signed in the user's own wallet.

Independent project, not affiliated with Anthropic.
